# Repo Working Rules

Follow `README.md` instructions.

## Preservation Rules
- Do not remove manually added commented-out code without asking first.
- Before proposing removal, understand and preserve the original rationale (for example: ready-to-use debugging snippets).
- During refactors, preserve existing comments unless they are clearly incorrect/outdated.
- When changing logic, update comments and add new comments as needed to keep explanations at least as clear as before.
